# דרך כהנים - לקוח ווב

לקוח הווב של דרך כהנים. אפליקציית ניווט חי בסגנון ווייז שנמנעת מאזורים האסורים לכהנים, מאמתת כל מסלול לפני הצגתו, ומציגה את הוודאות בכל רגע. Vite + React + TypeScript.

## הרצה מהירה

```
npm install
npm run dev
```

השרת עולה על http://localhost:5173. ברירת המחדל היא מצב הדגמה, כך שהממשק עובד במלואו גם ללא שרת. אפשר להיכנס ולנווט מיד.

פקודות נוספות:

```
npm run build       בדיקת טיפוסים ובניית production
npm run typecheck   בדיקת טיפוסים בלבד
npm run preview     תצוגה מקדימה של תוצר הבנייה
```

## מצב הדגמה (Mock)

הדגל `VITE_MOCK` שולט על מקור הנתונים. כשהוא דלוק (ברירת מחדל) כל הקריאות מוגשות מפיקסצ'רים מקומיים בתוך הדפדפן, ללא רשת:

- חיפוש יעדים על מאגר מקומות אמיתי בגוש דן ובירושלים, כולל דירוג, הדגשת התאמות וזיהוי צמד קואורדינטות
- מקומות שמורים ואחרונים נטענים מיידית מאחסון מקומי
- חישוב מסלול שמצייר עקיפה ריאלית, מסמן מסלול נקי מול מסלול שנחסם באזור, ומחזיר רשימת הנחיות עם אזהרות אזור
- שכבות אזורים לפי רמת חומרה, מצטברות
- ניווט חי וסימולציה שמריצה את המסלול, כולל דיווח התקדמות והתראות אזור
- אירועי מסלול לדוגמה: עומסי תנועה, ודיווחי משתמש (משטרה, תאונה, מפגע, חסימה)

הקוד של מצב ההדגמה נמצא תחת `src/api/mock`. אותו חוזה `ApiClient` (ב-`src/api/types.ts`) ממומש גם מול שרת אמיתי ב-`src/api/httpClient.ts`, כך שהחלפה בין השניים היא רק שינוי דגל.

טיפים לבדיקה במצב הדגמה:

- הקלדת "שגיאה" או "error" בשדה החיפוש מדמה כשל של שירות החיפוש ומציגה את מצב השגיאה עם כפתור ניסיון חוזר
- יעד בתוך אזור, למשל "בית העלמין סגולה", מפעיל את מסך הכישלון: לא נמצא מסלול נקי

## חיבור לשרת אמיתי

יש להעתיק את `.env.example` ל-`.env` ולכבות את מצב ההדגמה:

```
VITE_MOCK=false
```

בפיתוח, קריאות ל-`/api` עוברות proxy אל `http://localhost:3000` (מוגדר ב-`vite.config.ts`). אפשר לעקוף את כתובת השרת עם `VITE_API_BASE`.

## מפתחות סביבה

| משתנה | תיאור |
|-------|-------|
| `VITE_MOCK` | מצב הדגמה עם פיקסצ'רים מקומיים. ברירת מחדל: דלוק |
| `VITE_GOOGLE_MAPS_KEY` | מפתח דפדפן של Google Maps. ריק מפעיל מפה סכמטית מקומית |
| `VITE_GOOGLE_CLIENT_ID` | מזהה לקוח של Google Identity לכפתור ההתחברות. ריק מנטרל אותו |
| `VITE_API_BASE` | עקיפת כתובת השרת. ריק פירושו אותו origin |
| `VITE_GA_MEASUREMENT_ID` | מזהה מדידה של GA4. ריק משאיר את המדידה מנוטרלת לחלוטין |
| `VITE_CONTACT_EMAIL` | כתובת ליצירת קשר בענייני פרטיות ונתונים, מוצגת בתחתית עמודי המדיניות. ריק מסתיר את הפסקה |

כשאין מפתח מפות, כל מסך שמציג מפה נופל אוטומטית ל**מפה סכמטית** מקומית שמציירת את אותה גיאומטריה: אזורים, מסלול, אירועים ורכב. כך אפשר לסקור את כל המוצר ללא חשבון חיוב.

## אסימוני עיצוב (Design Tokens)

מקור האמת לשפה החזותית הוא `derech-kohanim-shared/src/design/tokens.ts`. הגנרטור שם כותב את `src/styles/tokens.css`, שמכיל את כל הצבעים, הרדיוסים, הריווח, הטיפוגרפיה, הצללים, משכי האנימציה ומטרות המגע כמשתני CSS.

- אין לקבוע בקוד ערך צבע, רדיוס, ריווח, גודל גופן, צל או משך. תמיד דרך משתני ה-CSS
- בהיר וכהה נבחרים לפי `data-theme` על אלמנט השורש, עם נפילה להעדפת המערכת
- הגופן הוא Rubik, מאוחסן מקומית תחת `src/assets/fonts` (תת-קבוצות עברית ולטינית), ומיושם דרך המשתנה `--font-ui`. אין קריאות רשת חיצוניות לגופנים
- כדי לרענן את הטוקנים לאחר שינוי בקובץ המשותף: `npm run tokens` בתיקיית `derech-kohanim-shared`

## מדיניות ומחיקת חשבון

שלוש כתובות ציבוריות, מחוץ לשער האונבורדינג בכוונה: אפשר לקרוא אותן לפני אישור התנאים,
וגם מי שכבר התנתק או הסיר את האפליקציה יכול להגיע אליהן.

| כתובת | מה יש שם |
|-------|----------|
| `/terms` | תנאי השימוש. נטענים מהשרת (`GET /api/auth/terms`), כי זה המסמך המגורסה שהמשתמש מאשר. אם השרת אינו זמין מוצג העותק המצורף מקבצי השפה, עם הודעה שאומרת זאת |
| `/privacy` | מדיניות הפרטיות. חיה בקבצי השפה (`legal.privacyBody`), כי אין לה גרסה ואין אישור |
| `/delete-account` | טופס בקשה למחיקת החשבון והנתונים. שולח ל-`POST /api/account/deletion-requests` |

הטופס **רק רושם בקשה**, ומפעיל הקונסולה מאמת ומבצע. משתמש מחובר רואה את הכתובת שלו
לקריאה בלבד, כי היא זו שנרשמת בכל מקרה. הקישורים לשני המסמכים מופיעים בהגדרות, בשלב
התנאים באונבורדינג ובטופס ההרשמה, ונפתחים בלשונית חדשה כדי לא לאבד את התהליך.

## ריבוי שפות וכיווניות

עברית היא ברירת המחדל (RTL), אנגלית משנית (LTR). החלפת שפה חיה מהגדרות מהפכת גם את `dir` של המסמך ואת כל הפריסה. הכל דרך מפתחות תרגום ב-`src/i18n/locales`, ללא מחרוזות קשיחות. הפריסה משתמשת ב-logical properties בלבד (inline-start/end), כך שההיפוך אוטומטי. הנחיות "ימינה/שמאלה" נשארות נכונות גיאוגרפית ואינן מתהפכות עם ה-RTL.

## מבנה

```
src/
  api/            חוזה הלקוח, לקוח HTTP עם ניהול טוקנים, ומצב הדגמה
  components/
    ui/           ספריית הרכיבים על גבי הטוקנים
    search/       שדה חיפוש היעד וההשלמה האוטומטית
    map/           מפת גוגל, מפה סכמטית, ובקרות המפה
    certainty/    מחוון הוודאות בשלושת מצביו
    layout/       כותרות מסך
    auth/         כפתור גוגל
  navigation/     מנוע ההרצה, אירועי מסלול, רשימת ההנחיות, ומסך הדיווח
  voice/          מנוע הקול והרכבת ההנחיות המדוברות
  screens/        מסכי המוצר
  state/          העדפות, אימות, ומצב הנסיעה
  i18n/           תרגומים והחלפת כיווניות
  lib/            עזרי פורמט, גיאומטריה, הדגשה, וקואורדינטות
```

## הקול

הנחיה קולית מורכבת ממקטעים, לעולם לא נקראת מהמסך. `src/voice/phrase.ts` מרכיב את המשפט המדובר מתוך השדות המובנים של ההנחיה: מקדים, מרחק מעוגל לסולם הסגור, פעולה, ורחוב. הטקסט שעל המסך והמשפט המדובר הם שתי הצגות נפרדות של אותה הנחיה. סולם הנפילה: מקטעים מוקלטים, ואם אין, מנוע הדיבור של הדפדפן עם המשפט המורכב, ואם אין, טקסט בלבד. הניווט לעולם אינו ממתין לשמע.

## בדיקה עצמית

הצילומים בתיקיית `scratch-shots` נלכדו בהרצה אמיתית של הדפדפן על מצב ההדגמה, ומכסים את שדה החיפוש, סקירת המסלול, הניווט החי, בקרות המפה, רשימת ההנחיות, מסך הדיווח, וכיווניות RTL ו-LTR.
